# 睡不着的时候：几个可以尝试的方向

> 工程占位语料（提纲级）。正式上线前需由具备心理学背景的人员重写与审校。

## 先分清三种情况

- **入睡困难**：躺下后长时间无法入睡
- **睡眠维持困难**：夜里反复醒、醒了难以再睡
- **早醒**：比计划时间早很多醒来且无法再入睡

三种情况的应对重点不同，先分清自己是哪一种，比笼统地"想办法睡好"更有效。

## 睡眠卫生要点

1. 固定起床时间，比固定入睡时间更重要。
2. 白天有光照与活动，傍晚后减少强光。
3. 下午之后减少咖啡因摄入。
4. 睡前一小时离开屏幕，尤其是容易让人兴奋的内容。

## 刺激控制：把床和睡眠重新绑定

躺下约二十分钟仍睡不着，就起身到别处做安静的事，有困意再回床。目的是避免让床变成"躺着焦虑的地方"。这条做起来辛苦，但通常是最见效的一条。

## 睡前反刍怎么办

把担心的事写在纸上，并写一句"明天几点处理它"。写下来这个动作本身就能减少大脑反复提醒的需要。

## 什么时候该去看医生

持续一个月以上、每周三次以上，或已经明显影响白天状态时，建议就诊。不要自行使用助眠药物。
