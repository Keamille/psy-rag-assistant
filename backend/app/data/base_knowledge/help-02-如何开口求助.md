# 如何开口求助：把困难说清楚

> 工程占位语料（提纲级）。正式上线前需由具备心理学背景的人员重写与审校。

## 为什么难开口

常见顾虑有三类：怕给别人添麻烦、怕被评价、怕说不清楚。前两类属于心理门槛，第三类则可以通过准备来解决。

## 一个四句话的结构

向朋友、家人或医生描述时，按这四句组织通常就够用了：

1. **状态**：我最近睡得不好，差不多两周了。
2. **影响**：白天几乎没法集中做事。
3. **想法**：我总觉得自己拖累了别人。
4. **请求**：我想找个专业人士看看，你能陪我去吗？

## 如果是去医院

提前写下三件事，进诊室直接递给医生也可以：

- 什么时候开始的，有没有明显诱因
- 最主要的三个感受或症状
- 睡眠、食欲、工作状态的变化

## 如果暂时不想告诉认识的人

可以先打心理援助热线，或者先写下来。写下来的过程本身就是一次整理，很多人是在这一步才发现自己真正想说的是什么。

## 关于保密

咨询与医疗都有保密原则，但也有依法需要介入的例外情形（例如涉及自伤、伤人的风险）。开口前可以先问清楚对方所在机构的保密范围。
